APRM Lucky Draw Cloud v9
- Correct Firebase API key in operator, 2-digit and 3-digit pages.
- Radar now shows live-looking target blips based on currently eligible participants.
  Up to 42 blips are drawn to keep the radar readable; winners disappear as the eligible pool changes.
- Operator settings now have separate ×2 / ×3 / ×4 / ×5 number fields.
- A number cannot be saved in more than one multiplier group.
- Weight groups are cloud-synced and used by both draw modes.
- Existing older single-weight data remains backward compatible until new weight groups are saved.
