Eligible numbers

One shared participant list is used by both draw modes. Default: 001–180. The 2-digit draw uses IDs 001–099 and displays them as 01–99; the 3-digit draw uses IDs 001–180. A winner in either mode is automatically excluded from both modes. Settings are shared through Firebase Cloud Firestore. Saving here updates every draw device.

Weighted Draw Demo

Client-comparison mode. Numbers entered here receive the selected weight. Example: with ×2, each listed number has twice the selection weight of each normal eligible number. This setting is shared by the 2-digit and 3-digit draw screens.
